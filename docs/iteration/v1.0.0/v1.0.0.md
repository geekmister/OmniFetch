# v1.0.0 迭代文档



## 事件一

检查当前项目架构是否是使用`Electron Vite`构建，参考模板是`electron-vite-vue`（Github：https://electron-vite.github.io/），如果不是，需要迁移成`Electron Vite`构建。

### 迁移改造方案

#### 1. 现状诊断（结论：非 Electron Vite 构建）

当前项目基于社区插件 `vite-plugin-electron` + `vite-plugin-electron-renderer` 搭建，与官方 `electron-vite-vue` 模板存在以下差异：

| 维度 | `electron-vite-vue`（目标） | 当前项目 | 是否一致 |
|------|------------------------------|----------|----------|
| 核心依赖 | `electron-vite` | `vite-plugin-electron` / `vite-plugin-electron-renderer` | ❌ |
| 配置文件 | `electron.vite.config.ts`（main/preload/renderer 三段） | 单一 `vite.config.ts` 手动挂插件 | ❌ |
| 启动脚本 | `electron-vite dev` | `vite` + `electron .` 分离 | ❌ |
| 构建脚本 | `electron-vite build` | `vite build` + `electron-builder` | ❌ |
| preload 处理 | 原生支持 TS 编译 | 额外写 `copy-preload-cjs` 插件拷贝 `preload.cjs` 绕过 ESM | ❌ |
| 目录结构 | `electron/{main,preload,renderer}` 分离 | `electron/` 混放 `main.ts`/`preload.ts`/`preload.cjs` | ⚠️ |

> 证据：`package.json` 的 `devDependencies` 无 `electron-vite`；全仓库无 `electron.vite.config.ts`；`vite.config.ts` 通过 `electron([{ entry: 'electron/main.ts' }])` 手动挂载。

#### 2. 迁移目标

将构建体系从 `vite-plugin-electron` 平滑迁移到官方 `electron-vite`，消除 `preload.cjs` 拷贝 hack，统一为声明式三段配置，保持现有功能（yt-dlp 调用、IPC 通信、二进制路径解析）不变。

#### 3. 实施步骤

**步骤 1：依赖调整**
- 安装：`npm i -D electron-vite`
- 移除：`npm un vite-plugin-electron vite-plugin-electron-renderer`
- 保留：`vite`、`@vitejs/plugin-vue`、`vue-tsc`、`electron-builder`、`typescript`

**步骤 2：新增 `electron.vite.config.ts`（替换 `vite.config.ts`）**

```ts
import { defineConfig } from 'electron-vite'
import vue from '@vitejs/plugin-vue'
import { resolve } from 'path'

export default defineConfig({
  main: {
    build: {
      rollupOptions: {
        external: ['electron'],
      },
    },
  },
  preload: {
    // electron-vite 原生编译 TS preload，无需 .cjs 拷贝 hack
  },
  renderer: {
    resolve: {
      alias: {
        '@': resolve('src'),
      },
    },
    plugins: [vue()],
  },
})
```

**步骤 3：清理 preload 拷贝 hack**
- 删除 `electron/preload.cjs` 及 `vite.config.ts` 中的 `copy-preload-cjs` 插件。
- 将 `electron/main.ts` 中 `preload: join(__dirname, 'preload.cjs')` 改为 `preload: join(__dirname, '../preload/index.js')`（由 electron-vite 输出）。

**步骤 4：规范 `electron/` 目录结构**

```
electron/
├── main/
│   └── index.ts        # 原 main.ts（BrowserWindow + ipcMain）
├── preload/
│   └── index.ts        # 原 preload.ts（contextBridge 暴露 electronAPI）
├── downloader.ts       # 保持不变
├── bin-resolver.ts     # 保持不变
└── ytdlp-updater.ts    # 保持不变
```

> `downloader.ts` / `bin-resolver.ts` / `ytdlp-updater.ts` 为共享模块，可保留在 `electron/` 根目录或移入 `electron/shared/`，main 与 preload 按需 import。

**步骤 5：更新 `package.json` 脚本**

```json
{
  "scripts": {
    "dev": "electron-vite dev",
    "build": "electron-vite build",
    "preview": "electron-vite preview",
    "download:bins": "node scripts/download-bins.mjs",
    "electron:build": "npm run download:bins && electron-vite build && electron-builder"
  }
}
```

> 移除原 `vue-tsc --noEmit && vite build` 中的 `vite build`（改由 `electron-vite build` 统一处理 renderer 类型检查与构建）；类型检查可保留在 CI 门禁中单独执行 `vue-tsc --noEmit`。

**步骤 6：对齐 `tsconfig`**
- 保留 `tsconfig.json`（renderer）+ `tsconfig.node.json`，新增 `tsconfig.main.json` 与 `tsconfig.preload.json`（参考 `electron-vite-vue` 模板），并在根 `tsconfig.json` 的 `references` 中引用。
- 确保 `electron/main/index.ts` 与 `electron/preload/index.ts` 的 `include` 覆盖到位。

#### 4. 风险与权衡

- **preload 路径变化**：`main.ts` 中 `preload` 路径需随 electron-vite 输出目录调整，否则打包后白屏。
- **`__dirname` 兼容**：electron-vite 的 main/preload 默认编译为 CJS，原 `main.ts` 中 `import.meta.url` 写法需改为 `require` 风格或确认编译产物格式；建议统一使用 `__dirname`（CJS 输出）以避免 ESM 路径问题。
- **`extraResources` 不变**：`bin/` 目录仍通过 `electron-builder` 的 `extraResources` 拷贝，迁移不影响二进制资源加载逻辑。
- **回滚方案**：保留 `vite.config.ts` 备份，若 electron-vite 构建异常可临时切回 `vite-plugin-electron`。

#### 5. 验收标准

- [ ] `npm run dev` 等价于原 `vite` + `electron .`，窗口正常加载、yt-dlp 功能可用。
- [ ] `npm run electron:build` 产出可安装包，二进制 `bin/` 正确打包。
- [ ] 仓库中无 `preload.cjs` 及 `copy-preload-cjs` 插件残留。
- [ ] 存在 `electron.vite.config.ts`，`package.json` 依赖含 `electron-vite`、不含 `vite-plugin-electron`。
- [ ] `vue-tsc --noEmit` 类型检查通过（CI 门禁）。
